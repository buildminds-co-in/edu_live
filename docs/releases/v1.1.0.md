# Release v1.1.0 — 2026-11-14

**Type:** minor
**Released by:** buildminds
**Approved by:** buildminds (release PR review); feature PRs reviewed by jameel-outskill

## Changes
- Question papers: source budget per chapter raised from 10k to 30k characters, so a full answer key fits alongside its questions (#5)
- Question papers: system prompt covers questions and answer keys in separate documents; answers are matched by question wording and copied only when the question matches; when none is found the model writes the answer from syllabus knowledge without calling it official (#5)
- Raw PDFs table shows whether a document is eligible for question papers and its subject, e.g. "Yes (Science)" (#3)
- Question-paper chapter checkboxes fall back to the filename when no chapter name was entered at upload (#4)
- Ingestion: whole-PDF enrichment timeout raised from 60s to 180s; multi-page papers were being cut off and falling back to plain text (#6)

## Database migrations
- None (no new files in `worker/migrations/`). `wrangler d1 migrations list --remote --env production` reports no pending migrations.
