## Changes
- Widget: an expand button (⤢ / ⤡) in the widget header fills the whole page and restores the previous width; the choice is remembered with the width. Dragging the left edge now goes up to the full page width (was capped at half the screen), minimum 300px. (#20)
- Widget fix: dragging stopped as soon as the pointer crossed into the chat; it now works across the whole panel. Expanded and phone views fit the visible page instead of sliding under a host-page scrollbar. (#20)
- Deploys: `npm run deploy:staging` / `deploy:prod` deploy the Worker and the frontend together, both tagged with the release version; prod deploys only from a clean `vX.Y.Z` tag. (#19)
- Evals (developer tool, not student-facing): two suites, `npm run eval:golden` and `npm run eval:client` (15 cases from the four Edukripa sample papers; official PDFs go in `worker/evals/reference-papers/`, gitignored). (#20)
- Docs: CLAUDE.md was in the file twice since v1.1.4, cut off mid-sentence; now one copy. Merge-back PRs use merge commits. (#19, #20)
- The release branch merges `main` back into the `staging` line, so release PRs stop conflicting after the earlier squash-merged merge-backs.
