# Release v1.1.6 — 2026-11-16

**Type:** patch (hotfix branch `hotfix/v1.1.6-generation-budget` → `main`)
**Released by:** buildminds
**Approved by:** buildminds (PR #17, merged by Naveed)

## Changes
- Question-paper generation has enough room for Maths. Maths papers failed at every size with "the AI model's response came back incomplete or malformed" because the reply was cut off at the output limit: prod Maths 20 used 4,776 of 4,800 tokens, Maths 60 16,738 of 16,800 (Science 20 used 1,764). Per-question budget 600 → 1,500, minimum 4,000 → 12,000, maximum 32,000 → 60,000. This is a ceiling only; billing is per token used.
- If a reply still can't be parsed, generation retries once with 1.5× the budget. Each attempt is recorded in transactions (the retry is labelled "(retry 1)", and the max_tokens used is in the input summary). A failed LLM call itself still fails at once, as before.
- The 60-mark option stays off in the student app (removed in v1.1.5), by owner decision, until it can be tested; staging Maths 60 did generate (see below). 70 stays removed. The student app is unchanged from v1.1.5.
